# Калькулятор мастер-классов Каталиста

Живая страница: https://kalkulyator-mk.vercel.app

Сайт обновляется сам: сохранили правку в ветке `main` репозитория на GitHub, через 1-2 минуты
она на странице.

Нет доступа к GitHub: правьте файлы у себя, прогоните `npm test` и пришлите Марии изменённые
`mk.json` и `template.html`, она выкатит их на сайт.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `mk.json` | прайс мастер-классов: 268 позиций |
| `template.html` | вёрстка, формулы, активности (массив `ACTS`), наценка |
| `build.py` | собирает страницу из `template.html` и `mk.json`, проверяет прайс |
| `test-formulas.mjs` | сверка формул с эталонными числами таблицы |

## Как поправить цену или добавить мастер-класс

Откройте `mk.json` на GitHub, нажмите карандаш, правьте, внизу «Commit changes».

Одна позиция выглядит так:

```json
{"n": "Бомбочки для ванн", "c": [350, 320, 300], "k": "Духи", "a": "с 10 лет"}
```

- `n`: название
- `c`: цена за участника, ₽, для групп до 50 человек / от 51 до 99 / от 100 человек
- `k`: категория (необязательно)
- `a`: возраст (необязательно)
- если цены нет: `"c": null` и пояснение в `"note"`

Позиции разделяются запятой. Если в файле ошибка (лишняя запятая, цена текстом), сборка
остановится, а на сайте останется прошлая рабочая версия. Причина будет видна в GitHub
рядом с коммитом (красный крестик, ссылка «Details»).

## Локально

```bash
npm install   # один раз
npm test      # собрать страницу и сверить формулы с таблицей, ждём «ИТОГ: 6/6»
```

Нужны Python 3, Node.js и Google Chrome. Если Chrome стоит не в обычном месте, путь задаётся
переменной `CHROME_PATH`.

Правили формулы в `template.html`: сначала `npm test`, потом коммит. Сборка на сайте проверяет
только прайс, формулы проверяет этот тест.
