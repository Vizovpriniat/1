# Калькулятор мастер-классов «Вызов принят»

Живая страница: https://vizovpriniat.github.io/1/

Сайт обновляется сам: сохранили правку в ветке `claude/online-calculator-changes-kjpp85`
репозитория на GitHub, через 1-2 минуты она на странице (GitHub Actions пересобирает
и публикует через GitHub Pages).

Нет доступа к GitHub: в самом калькуляторе внизу есть раскрывающаяся панель «Прайс и
категории» — там можно менять цены, добавлять мастер-классы/категории и правки для
активностей прямо в браузере, без GitHub. Правки видно сразу же, но они сохраняются
только в этом браузере — чтобы стали видны всем на сайте, нужно нажать «Скопировать»
и вставить результат в `mk.json` / `acts.json` на GitHub (как описано ниже), либо
переслать скопированное тому, у кого есть доступ.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `mk.json` | прайс мастер-классов: 268 позиций |
| `acts.json` | отдельные активности (Аэротату, Мехенди и т.д.): ставки и норма |
| `template.html` | вёрстка, формулы, наценка |
| `build.py` | собирает страницу из `template.html`, `mk.json` и `acts.json`, проверяет оба файла |
| `test-formulas.mjs` | сверка формул с эталонными числами таблицы |

## Как поправить цену или добавить мастер-класс

Откройте `mk.json` на GitHub, нажмите карандаш, правьте, внизу «Commit changes».

Одна позиция выглядит так:

```json
{"n": "Бомбочки для ванн", "c": [350, 320, 300], "k": "Духи", "a": "с 10 лет"}
```

- `n`: название
- `c`: цена за участника, ₽, для групп до 50 человек / от 51 до 99 / от 100 человек
- `k`: категория (необязательно)
- `a`: возраст (необязательно)
- если цены нет: `"c": null` и пояснение в `"note"`

Позиции разделяются запятой. Если в файле ошибка (лишняя запятая, цена текстом), сборка
остановится, а на сайте останется прошлая рабочая версия. Причина будет видна в GitHub
рядом с коммитом (красный крестик, ссылка «Details»).

## Как поправить активность

Так же, но в `acts.json`. Одна позиция:

```json
{"n": "Аэротату", "h1": 4500, "hx": 3500, "per": 15, "note": "3 до 5 минут на участника"}
```

- `n`: название
- `h1`: ставка мастера за первый час, ₽
- `hx`: ставка за каждый следующий час, ₽
- `per`: сколько участников успевает один мастер за час (норма)
- `note`: комментарий, показывается в калькуляторе
- `est`: необязательное поле, `1` — если ставка не из таблицы, а прикидка (в калькуляторе
  тогда появляется предупреждение)

Цену за участника для активности вводят прямо в калькуляторе под каждую сделку. По умолчанию
подставляется рекомендуемая: такая, чтобы выйти на стандартную наценку (1,67).

## Маржа

Маржа = прибыль ÷ цена клиенту. Если общая маржа ниже 35%, итог справа горит красным: такое
не продаём. Порог задан константой `MIN_MARGIN` в `template.html`.

## Локально

```bash
npm install   # один раз
npm test      # собрать страницу и сверить формулы с таблицей, в «ИТОГ» все проверки должны пройти
```

Нужны Python 3, Node.js и Google Chrome. Если Chrome стоит не в обычном месте, путь задаётся
переменной `CHROME_PATH`.

Правили формулы в `template.html`: сначала `npm test`, потом коммит. Сборка на сайте проверяет
только `mk.json`/`acts.json`, формулы проверяет этот тест.
